Privacy Policy for AOTY Release Bridge

Last updated: September 20, 2026

AOTY Release Bridge helps users copy release information from supported Bandcamp and Spotify album pages into Album of the Year (AOTY).

Data the extension handles

The extension reads the current supported album page only after the user clicks Add Release. It may process the album title, artist name and artist link, release type, release date, and source page URL. It also reads the relevant AOTY add-release page so it can search for matching artists and releases and fill the form.

How the data is used

This information is used only to provide the extension's user-facing release import feature. A temporary release draft and its tab association are stored locally in Chrome extension storage so the workflow can continue across AOTY navigation and sign-in. The draft is deleted when the workflow ends, when its AOTY tab closes, or when it expires after seven days.

Data sharing and transmission

The developer does not receive, collect, sell, or share this information. The extension has no analytics, advertising, tracking, or developer-operated server. It reads album information already displayed by Bandcamp or Spotify and writes it into AOTY form fields. AOTY receives the form data through its normal website behavior only if the user reviews and submits the form.

User control and retention

The user starts data processing by clicking Add Release on a supported album page. Ending the import, closing its AOTY tab, removing the extension, or clearing its extension data removes the applicable locally stored draft. Chrome may also clear session data when the browser session or extension is restarted.

Permissions

The extension uses Chrome's storage permission to keep a temporary release draft and associate it with the correct AOTY tab. It runs only on supported Bandcamp, Spotify, and Album of the Year pages needed for the import workflow.

Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. The extension uses data only to provide its single release-import purpose and does not use it for advertising, profiling, creditworthiness, or unrelated purposes.

Contact

For privacy questions, use the developer contact or support channel listed on the extension's Chrome Web Store page.
